# XRay Image Classification

This project implements deep learning models for the classification of chest X-ray images.

## Purpose

The objective is to accurately classify X-ray images using convolutional neural networks.

## Methodology

- Utilizes TensorFlow and Keras to build and train models on grayscale image data.
- Includes data preprocessing, model training, evaluation, and results reporting.

## Requirements

- Python (compatible version)
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Usage

1. Install the required dependencies (`requirements.txt`).
2. Run `xray_classification.ipynb` in Jupyter Notebook.
3. Follow instruction cells for training, evaluation, and result visualization.

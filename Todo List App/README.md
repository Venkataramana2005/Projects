# Todo List App

## Project Title
Todo List Application

## Objective
This project aims to develop a comprehensive task management application that enables users to create, read, update, and delete (CRUD) todo items efficiently. The application provides a RESTful API backend for managing tasks with persistent storage using a database.

## Methodology

### Technology Stack
- **Programming Language**: Python 3.x
- **Web Framework**: FastAPI
- **Database ORM**: SQLAlchemy
- **Database**: SQLite
- **API Architecture**: RESTful API

### Key Components
1. **app.py**: Main application file containing FastAPI endpoints and business logic
2. **database.py**: Database configuration and SQLAlchemy setup
3. **practice.py**: Development and testing utilities

### Features
- Create new todo items
- Retrieve all todo items
- Update existing todo items
- Delete todo items
- Persistent data storage using SQLite database

## Requirements

To run this application, install the following dependencies:

```bash
fastapi
uvicorn
sqlalchemy
```

Install all required packages using:

```bash
pip install fastapi uvicorn sqlalchemy
```

## Usage Instructions

### Running the Application

1. Navigate to the project directory:
```bash
cd "Todo List App"
```

2. Start the FastAPI server:
```bash
uvicorn app:app --reload
```

3. The application will be accessible at:
```
http://localhost:8000
```

4. Access the interactive API documentation:
```
http://localhost:8000/docs
```

### API Endpoints

The application provides the following RESTful endpoints:

- **GET /todos**: Retrieve all todo items
- **POST /todos**: Create a new todo item
- **PUT /todos/{id}**: Update an existing todo item
- **DELETE /todos/{id}**: Delete a todo item

### Database

The application uses SQLite database for persistent storage. The database file will be automatically created upon first run.
